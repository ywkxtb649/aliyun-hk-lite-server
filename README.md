## 线路质量：200Mbps 峰值是真的，大陆访问快是另一回事

先给结论：200Mbps 实测能跑出标称水平，但国际型走的是 BGP 非中国优化线路（官方标注 BGP_NCO），官方对它的定位就是国际访问，大陆用户访问不建议选这条线。其他规格族虽然标注 BGP 优化线路，也别按精品线路的预期来买——2024 年底一份针对 200M 套餐的回程路由追踪显示，电信方向走的是普通 163 骨干网直连内地，深圳方向走联通 CUG。属于“能用、够稳”的级别，跟 CN2、GIA 那类精品跨境线路是两个概念。

## 常见问题

**阿里云香港轻量服务器需要备案吗？**

不需要。备案只针对内地地域的网站，香港实例把域名解析绑定到公网 IP 就能访问。

**30Mbps 带宽实际下载多快？**

30Mbps 指比特每秒，换算成文件下载速度理论上限约 3.7MB/s。200Mbps 档实测能跑到标称值附近，但注意长时间跑满会触发限流。

**到期不续费会怎样？**

实例先自动停机，超过保留周期后实例、快照、自定义镜像一起释放，数据无法找回。重要数据定期做快照，并手动导出备份文件。

**以后能升级成 ECS 吗？**

不能一键转换。业务长大后只能通过自定义镜像或 rsync 同步的方式整体迁移到 ECS，迁移成本不低，一开始就把规格选对更省事。

**网站部署完为什么访问不了？**

大概率是漏了控制台防火墙。轻量产品是双层防护：控制台防火墙加系统内 firewalld，各管各的。部署 Web 服务后，除了在服务器里放行 80/443 端口，还要在轻量控制台的防火墙规则里放行，缺一层都进不来。如果部署了数据库，3306 端口务必保持对公网关闭。
